# Учет оборудования предприятия

Простое WPF-приложение на C# и .NET 8. Данные сохраняются в SQLite.

## Запуск

Откройте `EquipmentAccounting.sln` в Visual Studio 2026, выберите проект `EquipmentAccounting.App` как запускаемый и нажмите `F5`. При первом старте автоматически создается база `%LOCALAPPDATA%\EquipmentAccounting\equipment.db` с тремя примерами оборудования.

## Что умеет приложение

- показывать список оборудования;
- искать по названию и инвентарному номеру;
- добавлять, редактировать и удалять записи;
- проверять обязательные поля, уникальность номера, стоимость и дату покупки;
- показывать количество единиц и их общую стоимость.

Форма записи содержит название, инвентарный номер, производителя, дату покупки, стоимость, подразделение, дату осмотра и краткую заметку о ремонтах.
